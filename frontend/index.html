บัญชีตัวอย่าง

คู่มือการใช้งาน & โครงสร้างระบบ

ระบบมีการจำกัดสิทธิ์การเข้าถึงข้อมูล กรุณาใช้บัญชีที่ได้รับมอบหมายเพื่อเข้าสู่ระบบตามบทบาทของคุณ

1. สำหรับเกษตรกร (Farmer Portal)

วัตถุประสงค์: ติดตามผลการส่งมอบเมล็ดกาแฟของตนเองอย่างโปร่งใส

  • การเข้าสู่ระบบ: ใช้บัญชีที่ได้รับมอบหมาย (เช่น farmer01) เพื่อเข้าสู่หน้าแดชบอร์ดส่วนตัว
  • การตรวจสอบประวัติ: สามารถดูตาราง "ประวัติการส่งมอบ" ของตนเองได้แบบเรียลไทม์
  • สถานะและยอดเงิน: ติดตามสถานะประเมิน (ผ่านเกณฑ์/ไม่ผ่าน) หากผ่านเกณฑ์ ระบบจะแสดงยอดเงินที่ได้รับ พร้อมสถานะ "รอโอนเงิน" หรือ "จ่ายแล้ว" ทันที

2. สำหรับเจ้าหน้าที่ตรวจคุณภาพ (QC Portal)

วัตถุประสงค์: บันทึกข้อมูลรับซื้อหน้าลาน และประเมินเกรดวัตถุดิบอัตโนมัติ

  • ขั้นตอนการบันทึก (Walk-in): ระบุชื่อเกษตรกร, เลือกสายพันธุ์กาแฟ, ระบุน้ำหนัก (จำกัดไม่เกิน 10,000 กก./คิว) และค่าความชื้น
  • เกณฑ์ประเมินอัตโนมัติ: ระบบจะประเมินผ่านเกณฑ์ก็ต่อเมื่อ ค่าความชื้นต้องไม่เกิน 12% หากเกินกว่านี้ระบบจะปัดตกเป็นสถานะ "ไม่ผ่าน" อัตโนมัติ
  • การจัดการข้อมูล: มีสิทธิ์ลบข้อมูลในตารางประวัติการตรวจรับล่าสุดเพื่อล้างคิวที่บันทึกผิดพลาดได้ทันที

3. สำหรับผู้บริหาร (Executive Dashboard)

วัตถุประสงค์: ดูภาพรวมธุรกิจ อนุมัติสั่งจ่ายเงิน และนำสถิติไปวิเคราะห์

  • สรุปข้อมูลภาพรวม: ตรวจสอบจำนวนเกษตรกร, จำนวนคิวรออนุมัติ, ปริมาณรับซื้อผ่านเกณฑ์ และยอดจ่ายเงินสดรวม
  • สถิติ (Charts): วิเคราะห์กราฟสัดส่วนปริมาณการรับซื้อตามสายพันธุ์ และกราฟแท่งกระแสเงินสดแบบ Real-time
  • การอนุมัติสั่งจ่ายเงิน: ตรวจสอบรายการจัดซื้อที่ผ่าน QC แล้วกดปุ่ม "จ่ายเงิน" เพื่ออนุมัติและเปลี่ยนสถานะไปยังฝั่งเกษตรกร

4. โครงสร้างและเทคโนโลยีระบบ (System Architecture)

ภาพรวมของ Tech Stack ที่ใช้ในการพัฒนาโปรเจกต์

ส่วนแสดงผล (Frontend)
  • UI & Styling: HTML5, Tailwind CSS
  • Logic: Vanilla JavaScript (ES6)
  • Icons: Lucide Icons
  • Hosting: GitHub Pages
ส่วนประมวลผล (Backend)
  • Server: Node.js & Express.js
  • Database: PostgreSQL (บริหารด้วย Prisma ORM)
  • API: RESTful API
  • Hosting: Render.com
ความปลอดภัยและการสื่อสาร (Security & Comms)
  • Authentication: ตรวจสอบสิทธิ์ผ่าน JWT (JSON Web Token)
  • State Management: จัดการ Session ผ่าน localStorage
  • Data Fetching: เชื่อมต่อหน้าบ้านและหลังบ้านด้วย Fetch API & CORS
